# طراحی فیگما

فایل [diamond-trading-figma.pdf](diamond-trading-figma.pdf) خروجی یک‌صفحه‌ای فیگمای اپ «توکن الماس» است و حدود ۳۳ مگابایت حجم دارد.
این فایل مستند API نیست، طراحی UI است. صفحه‌هایی مثل خرید و فروش توکن، پیش‌خرید اقساطی، تسهیلات نقدی، توکن هدیه و تاریخچهٔ تراکنش‌ها در آن هست.

## یادداشت‌های بخش پیش‌خرید اقساطی (BNPL)

- این بخش در ردیف y≈1700 تا 3600 (واحد pt) صفحه است.
- متن‌ها با `pdftotext -bbox` خوانده شدند.
- این اعداد از فیگما درآمده و در کد و تست‌ها (`test/BnplService.Tests/Domain/QuoteTests.cs`) بررسی شده‌اند:
  - مبلغ پیش‌فرض ۵۰٬۰۰۰٬۰۰۰ ریال، ۱۲ قسط، کارمزد ۲۲٪.
  - ۴٪ از کارمزد در قسط اول گرفته می‌شود.
  - قسط اول ۶٬۹۱۶٬۶۶۰ ریال، بقیهٔ اقساط ۴٬۹۱۶٬۶۶۰، جمع ۶۰٬۹۹۹٬۹۲۰.
  - تخفیف فقط از قسط آخر کم می‌شود.
  - جریمهٔ دیرکرد روزانه ۱٪ مبلغ قسط است.
  - قسط اول باید ۳۰ دقیقه بعد از امضای قرارداد پرداخت شود.
  - شمارهٔ قرارداد شکل `P5_U` و ۷ رقم دارد.
- تعداد توکن با قیمت لحظهٔ پرداخت قسط اول قطعی می‌شود.
